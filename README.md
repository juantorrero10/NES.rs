## Installation:
 - Clone the repo:
```bash
git clone https://github.com/juantorrero10/NES.rs.git
cd NES.rd
```
 - Run release version (Debug is too laggy)
```bash
cargo run --release
```


## Controller Keybindings (Nes Controller -> Keyboard)
 - A => Space
 - B => Left Shift
 - Select => Backspace
 - Start => Enter
 - Up, Left, Down, Right => W, A, S, D
